# 📝 My Todo App

Una moderna applicazione Todo List costruita con **Vanilla JavaScript** e **Tailwind CSS**.

## ✨ Features

- ✅ Aggiunta, completamento e cancellazione task
- 💾 Salvataggio automatico in localStorage
- 🎨 Design moderno e responsive
- 🎉 Animazioni fluide e confetti per celebrare i completamenti
- 📊 Contatore task in tempo reale
- ⌨️ Supporto tasto Enter per aggiungere task
- 📱 Completamente responsive (mobile-first)

## 🛠️ Tecnologie utilizzate

- HTML5
- CSS3 (Tailwind CSS via CDN)
- Vanilla JavaScript (ES6 Modules)
- LocalStorage API
- Canvas Confetti

## 📦 Installazione

1. Clona il repository:
```bash
git clone https://github.com/tuousername/my-todo-app.git
cd my-todo-app
```

2. Apri `index.html` nel browser

Non serve installare dipendenze! 🎉

## 📂 Struttura del progetto
```
my-todo-app/
├── index.html          # Pagina principale
├── styles.css          # Animazioni CSS custom
├── index.js            # Entry point dell'applicazione
└── utils/              # Moduli utility
    ├── saveTodos.js
    ├── renderTodos.js
    ├── updateCounter.js
    └── celebrateCompletion.js
```

## 🎓 Cosa ho imparato

- Gestione dello stato con JavaScript puro
- Utilizzo di ES6 Modules per organizzare il codice
- Implementazione di animazioni CSS custom
- Design responsive con Tailwind CSS
- Persistenza dati con localStorage
